# 日日打卡（DayTick）

一個完全免費、資料只存在手機裡的 Android 習慣打卡 App。
重點功能：**桌面小工具直接點一下就能打卡**，不用打開 App。

## 功能

- **桌面小工具「待辦清單」**：標題顯示「待辦 已完成/總數」，點項目前面的圓圈就直接完成（劃掉），不會跳回 App；右上角 ＋ 可以快速新增
- **一次性待辦**：可以指定未來日期，到了那天會自動出現在清單和小工具；沒做完的會一直留著並標出逾期日期；完成的隔天自動收起來
- **每週重複事項**：選星期幾要做，依「早上 / 下午 / 晚上 / 隨時」分組
- 🔥 連續天數（沒排定的日子不會中斷連續）
- 紀錄頁：最近 12 週的打卡格子、最佳紀錄、30 天完成率；點格子可以補打卡
- 每個項目可設定表情符號、顏色（小工具的圓圈會用這個顏色）
- 支援深色模式與 Android 12 以上的動態配色

## 技術

Kotlin、Jetpack Compose（Material 3）、Jetpack Glance（桌面小工具）。
最低支援 Android 8.0（API 26）。不需要網路、不需要帳號。

## 怎麼把 App 裝到手機

需要先把程式碼「編譯」成 APK 安裝檔。以下兩種方法擇一。

### 方法一：用 GitHub 自動編譯（不用在電腦裝任何東西）

1. 程式碼已經在 GitHub 上了。
2. 點上方的 **Actions** 分頁，等「Build APK」跑完（約 5–10 分鐘，出現綠色勾勾）。
3. 點進那次執行，最下方 **Artifacts** 有 `DayTick-apk`，下載後解壓縮，得到 `DayTick-編號.apk`。

### 方法二：用 Android Studio 在 Windows 電腦上編譯

1. 下載安裝 Android Studio：<https://developer.android.com/studio>（安裝時全部用預設值）。
2. 開啟 Android Studio → **Open** → 選這個 `DayTick` 資料夾。
3. 第一次開啟會自動下載需要的元件（右下角有進度條），等它跑完。
4. 上方選單 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**。
5. 完成後右下角會跳出通知，按 **locate**，就能找到 `app-debug.apk`。
   （也可以用 USB 接上手機、開啟開發人員選項的 USB 偵錯，直接按綠色 ▶ 安裝。）

### 安裝到手機

1. 把 APK 傳到手機（LINE 傳給自己、Google 雲端硬碟、USB 都可以）。
2. 在手機上點開 APK，系統會問是否允許「安裝不明來源的應用程式」，允許即可。
3. 安裝完成後打開「日日打卡」。

### 加入桌面小工具

長按手機桌面空白處 → **小工具** → 找到「日日打卡」→ 把「待辦清單」拖到桌面，可以自由調整大小。
之後在小工具上點圓圈就完成，再點一次可以取消。

## 之後更新版本

APK 用一把固定的簽章金鑰簽名，金鑰存在 GitHub repository 的 **Settings → Secrets and variables → Actions**
（`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`），不會出現在公開的程式碼裡。
每次推送新程式碼，Actions 編出的新版 APK 都能直接覆蓋安裝，打卡紀錄會保留。

自己 fork 這個專案的人：沒設定這兩個 Secrets 也能編譯，只是會改用 debug 金鑰。

## 資安說明（個人使用）

- **不連網**：App 沒有申請網路權限，資料不會傳到任何伺服器，也沒有廣告或追蹤。
- **資料只在手機裡**：已關閉 Google 雲端備份；換手機時用「直接傳輸資料」仍可帶走紀錄。
- **其他 App 讀不到你的待辦**：只有啟動畫面與小工具這兩個 Android 規定必須公開的入口，其他 App 最多只能讓它重新整理畫面，讀不到也改不了內容；小工具的點擊動作都是不可竄改（immutable）的。
- **簽章金鑰**：金鑰只存在 GitHub Secrets（加密，公開 repository 的訪客和 fork 都讀不到），程式碼裡沒有任何密碼。
- **安裝來源**：只安裝從自己 GitHub Actions 下載的 APK。裝完後可以到設定把該 App（例如檔案管理或 LINE）的「安裝不明應用程式」權限關掉。
- **小工具內容**：待辦文字會顯示在桌面上，旁人看得到你的手機桌面時就看得到，這和你現在用的小工具一樣。
